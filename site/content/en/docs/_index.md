Blockstor is a Kubernetes control plane for LVM and ZFS storage with DRBD replication. It speaks a LINSTOR-compatible REST API, so `linstor-csi`, `piraeus-operator`, `ha-controller`, `golinstor` and the `linstor` CLI keep working unchanged.

Start with [Getting started](getting-started/), then see [Usage](usage/) for the full walkthrough.
