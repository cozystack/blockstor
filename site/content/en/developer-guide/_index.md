This section is for people who work on blockstor itself. If you want to run blockstor, the [Documentation](/docs/) is the place to start.

- [Building](building/): binaries, images and the local dev stand.
- [Testing](testing/): the test tiers, from unit tests to the operator CLI matrix.
- [Repository layout](repository/): where each part of the code lives.
- [Internals](internals/): the rules the code relies on, with references to it.
- [Contributing](contributing/): licensing rules, commits and pull requests.

Design notes and audits that are useful background but not part of this guide live in the repository's [`docs/`](https://github.com/cozystack/blockstor/tree/main/docs) directory.
